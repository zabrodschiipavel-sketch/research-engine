## Что это значит на практике (для этого бесплатного ключа, сегодня)

1. **Из 7 моделей реально отработали 3, и все — Flash-семейства.** Ни
   один Pro-вариант (3.1-pro-preview, 2.5-pro) не выполнился ни разу —
   `429` повторился идентично после 90-секундной паузы, то есть это не
   совпадение по таймингу, а похоже на отдельную (нулевую для free tier)
   квоту на Pro-тир, а не общий с Flash лимит запросов в минуту.
2. **`gemini-2.5-flash` и `gemini-2.5-flash-lite` сняты с публичного
   доступа** для новых ключей («no longer available to new users») —
   поколение 2.5 в Flash-варианте, судя по всему, уже полностью
   вытеснено линейкой 3.x на этом API.
3. **`gemini-2.0-flash` стабильно отвечает `500`** через новый
   Interactions API (не `404` — модель, видимо, существует, но сам
   эндпоинт с ней не справляется). Похоже на несовместимость старого
   поколения с новым API, а не на квоту — со старым `generateContent`
   он бы, вероятно, отработал, но `research_gemini.py` сейчас завязан
   именно на Interactions.
4. **Из двух рабочих младших моделей (3.1-flash-lite, 3-flash-preview)
   ни одна не вызвала ни одного инструмента** — обе ответили за один
   раунд из параметрической памяти, хотя `search_openalex` /
   `search_core` / `search_brave` были им доступны наравне с
   `gemini-3.5-flash`. Контент читается связно и по существу (см. файлы
   выше: RRF, min-max нормализация, sqlite-vec, размер чанка — всё на
   месте), но источники в конце — это общеизвестные страницы (Pinecone,
   Weaviate, FAISS/SQLite-доки), а не результат реального поиска. Это
   не «плохой ответ», а принципиально другой режим: без единого похода
   во внешние источники модель выдала правдоподобный, но негрунтованный
   текст. Для `research-engine`, где вся идея — агент сам решает, когда
   идти искать, это ключевой минус: облегчённые/превью-модели, похоже,
   реже считают нужным звать инструменты вообще, а не просто зовут их
   меньше раз.

## Вывод

На бесплатном ключе сегодня из всего зоопарка реально годится только
`gemini-3.5-flash` — единственная модель, которая и отработала, и
действительно пользовалась инструментами. `3.1-flash-lite` и
`3-flash-preview` дешевле и быстрее, но с этим промптом ни разу не
вышли за пределы собственной памяти — для дешёвых прикидочных ответов
это ок, для research-агента, которому нужно реальное покрытие
источников, не очень. Pro-модели и `2.0-flash` на этом ключе сейчас
недоступны вовсе (квота/несовместимость) — не обязательно навсегда,
но перепроверять смысла нет: `429` уже дважды воспроизвёлся
идентично.
